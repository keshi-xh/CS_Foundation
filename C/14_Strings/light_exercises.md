# Exercise 1: Strings

---

## Overview

In this exercise, you will deepen your understanding of C strings by implementing some of the most commonly used string functions from scratch. This will help you build the skills needed for more advanced projects.

---

## Task 1: Implement Your Own String Functions

Write your own versions of the following standard C string functions (do not use the built-in versions from `string.h`):

- `strcpy` &mdash; Copy one string to another
- `strlen` &mdash; Find the length of a string
- `strchr` &mdash; Find the first occurrence of a character in a string

For each function:

- Write the function definition in C
- Test it with example strings in your code
